# HE 공백 지도

동형암호(HE) 논문과 다른 프라이버시 기술 논문 1.7만 편을 기술 이름을 뺀 "무슨 문제인가"로 구 표면에 펼치고, 수요는 있는데 HE 연구가 없는 곳을 보여 주는 데모입니다.

- 지도의 모양은 수요 논문만으로 정했고, HE 논문은 문제가 비슷한 수요 논문 자리에 얹었습니다.
  - 파란 점이 없는 표면이 HE 연구가 안 온 곳입니다.
  - 주황 점: 주변(가까운 논문 50편)에 HE가 5% 이하인 수요 논문.
  - "HE만 보기"를 누르면 HE가 덮지 못한 표면이 그대로 빈 곳으로 보입니다.
- 마름모 하나는 하나의 문제입니다. 문제는 (데이터 분야 × 연산 × 참여 구조)로 나눕니다.
  - 분홍 마름모: 수요 논문은 5편 이상인데 HE 논문이 0편이고, 문제가 비슷한 논문 중에도 HE가 드문 문제.
  - 회색 마름모: 라벨상으로는 HE 0편이지만 문제가 비슷한 HE 논문이 있는 문제.
- 마름모를 누르면 문제 카드가 열립니다. 카드에는 다음이 나옵니다.
  - 수요 논문이 말하는 문제
  - 지금 쓰는 기술
  - 해마다 수요
  - 가장 비슷한 HE 논문
  - HE로 할 만한지
- 문제 문장과 분야·연산·참여 구조는 LLM이 자동으로 뽑은 것이며, 사람이 검수하지 않았습니다.
